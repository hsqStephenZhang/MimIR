### 5.3 在新多级 GPU 路径尚未接通 PyTorch 前端的前提下，如何打造最强论文？

针对 **PLDI / CGO / ASPLOS**，建议对论文架构做如下五点关键调整：

1. **果断将论文定位从“端到端 PyTorch 图编译器”切换为“多级张量编译器的可认证异步 GPU 协议降级（Certifying Asynchronous GPU Protocol Lowering in a Multi-Level Tensor Compiler）”**：
   - **输入层明确界定为**：MimIR 中的高层函数式张量规格（`map_reduce` / `Law`）+ 声明式多级调度项（`TileLevels`）。这与 **Halide、TVM TensorIR、Exo 2、Cypress、MLIR Transform Dialect** 的论文定位完全一致，彻底规避“PyTorch 前端只支持 CPU”的软肋（将 `mimir-frontend` 接通 GPU 诚实地列为独立进行中的前端工程）。
   - **核心研究问题（Research Question）**：*当现代 GPU 编译器将声明式多级张量调度自动降级为复杂的硬件异步流水（`cp.async`、Hopper TMA、`mbarrier` 奇偶握手、WGMMA 在途批次、warp specialization）时，如何在不牺牲生成代码性能（零运行时开销）且不编写数万行逐 kernel 人工证明（如 Koska 等人 34k 行 Lean 证明单个 GEMM）的前提下，静态认证每个生成 kernel 的异步同步协议无跨代污染（T1）、无读写覆盖竞争（T2）且无 ABA 假阳性？*

2. **将故事主线重构为“两级互补认证 + 协议与布局同处一 IR”的清晰架构**：
   - **第一层（IR 内置的类型化协议骨架与 $\mathbb{F}_2$ 布局守卫）**：
     - 展示 `gpu.mim` 中的 `SyncOf` 协议组合子（`async_ring`、`mbar_ring`、`shared_ring`、`consumer_ring`、`pingpong_ring`、`ring_fold`、`ws_fold`）与 `tensor.mim` 中的 $\mathbb{F}_2$ 布局一致性判定（`lies_sw128`、`lies_tma128`）。
     - 补上 `InFlight` → `release` 连接和 `ring_idle` 线性初始化后，明确声明类型层（核心依赖类型 + `check_sync`）静态保证的 4 条局部不变式：**令牌线性单次使用、环身份与面板句柄隔离、同一步内 `await → release` 两相顺序、`lag` 延迟释放与 WGMMA 在途批次守恒**。
   - **第二层（残余轨迹提取 + Lean 4 证明可靠的协议检查器）**：
     - 坦诚解释为什么纯类型系统（若不引入高代价的依赖循环组合子与模算术 SMT 求解）无法在不改变设备 IR 的前提下独立证明跨步的 `block % depth` 轮转对应与 `(block / depth) % 2` 奇偶回绕（直接引用 [`ringstate_report.md`](file:///home/chzh00001/workspaces/MimIR-thoughts/docs/reviews/ringstate_report.md) 的深刻分析——这会是 PLDI/CGO 审稿人非常欣赏的类型论洞见！）。
     - 由此自然引出 **Tristan–Leroy 式的逐实例残余证书验证**：在擦除前（或直接从 PTX）提取每个角色的代表线程事件流，交给 Lean 4 中证明了 `fold_of_accepted` / `readCode_of_accepted` $\Rightarrow$ T1 $\wedge$ T2 $\wedge$ `no_ABA` 的线性时间检查器。

3. **在提交前优先完成 3 项高性价比补强（预计总工作量 1–2 周）**：
   - **(a) 修好类型层的两个小缺口**：`InFlight` 接 `release`（[`gpu.mim:1188`](file:///home/chzh00001/workspaces/MimIR-thoughts/src/mim/plug/gpu/gpu.mim#L1188)）+ `ring_idle` 计入单次使用（[`check_sync.cpp:94-100`](file:///home/chzh00001/workspaces/MimIR-thoughts/src/mim/plug/gpu/phase/check_sync.cpp#L94-L100)），加上 `law.fastest` 接通 `check.verdict`（[`tensor.mim:3810`](file:///home/chzh00001/workspaces/MimIR-thoughts/src/mim/plug/tensor/tensor.mim#L3810)）。
