# MimIR Graph Pattern 参考用例覆盖

覆盖范围是本地 TVM Relax DPL 的 `test_dataflow_pattern.py`，以及下文列出的 MLIR PDLL／PDL 语义用例。这里记录可追溯的行为适配与剩余差异，不表示 Python API、PDLL 语言或完整编译器能力兼容。

## TVM DPL

参考 [test_dataflow_pattern.py](/workspaces/ml-compiler/tvm/tests/python/relax/test_dataflow_pattern.py) 的全部 **58 个顶层测试函数**；参数化函数在清单中只计一项。31 项为语义适配覆盖，22 项部分覆盖，5 项当前不支持。新增回归由指定 `gpt-6.1-sol` 的 Copilot CLI 编写并经本地复核补充，覆盖判断结合现有回归。

“语义适配覆盖”表示在当前 MimIR 表示中验证示例的核心行为；例如显式 `either` 可以覆盖两种交换顺序，不能据此声称存在自动交换律 API。“部分覆盖”保留图拓扑、捕获或 checked recipe 断言，同时列出未实现的 Relax 行为。返回 Unknown 或保持原图的边界测试不计作对应功能已实现。

新增 [pattern_dpl_extended.cpp](../test/pattern_dpl_extended.cpp) 的 26 个用例已通过 991 条断言，连同此前 [pattern_dpl.cpp](../test/pattern_dpl.cpp) 的 18 个用例，均纳入常规 CTest。图搜索使用 Indexed／Exhaustive 与正序／逆序候选，并检查独立指定的完整 anchor 集合和 captures。静态／符号 shape 用例检查已声明的 Arr 维度，不进行张量 shape 推导；连续重写用例显式执行两轮，不声称自动收敛。
